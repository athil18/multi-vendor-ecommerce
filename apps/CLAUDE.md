# Multi-Vendor E-Commerce Project

## gstack Integration

This repository is configured to use [gstack](https://github.com/garrytan/gstack) for AI software factory development workflows.

### gstack Slash Commands

- `/office-hours` — Product framing & strategy
- `/plan-ceo-review` — CEO & Founder product review
- `/plan-eng-review` — Technical architecture & spec design
- `/plan-design-review` — Frontend UI/UX design & anti-slop audit
- `/review` — Code review & bug detection
- `/cso` — Security & threat modeling (OWASP + STRIDE)
- `/qa` — Real browser automated QA
- `/ship` — Final PR release & deployment verification
