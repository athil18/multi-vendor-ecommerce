1. Authentication, Sessions & Multi-Tenant Authorization
Security Vector Previous System (Yesterday) Current Hardened System (Today)
Refresh Token Storage Critical Flaw
Stored in plaintext in user.refreshTokens. Database dump or SQL snapshot directly compromised active customer & vendor sessions. 		Hardened (SHA-256)
All refresh tokens are cryptographically hashed using SHA-256 prior to persistence. Raw tokens are never stored, preventing token replay attacks.
Session Invalidation / Logout Broken Revocation
logout route looked up hashed tokens while DB held raw strings. Session invalidation failed silently; revoked tokens remained valid until expiration. 		Verified Revocation
Unified SHA-256 hashing across AuthService, /api/auth/refresh, and /api/auth/logout. Session logout permanently purges the token.
Catalog Moderation (RBAC) Privilege Escalation
Sellers could self-approve items by transitioning pending_review -> approved via PATCH /api/seller/products/[id]/status, bypassing platform review. 		Enforced Isolation
Sellers are strictly restricted to draft and archived transitions. Approval & rejection transitions require authorized admin role.
Password Reset Workload Asymmetric Hashing
Password reset used 10 bcrypt salt rounds while registration used 12 rounds, creating unequal brute-force resistance across user accounts. 		Unified Salt Workload
Standardized to 12 bcrypt salt rounds across all password update flows, maximizing cracking resistance.
2. API Security, SSRF & Cryptographic Timing Defenses
Security Vector Previous System (Yesterday) Current Hardened System (Today)
Image Proxy SSRF Open Proxy SSRF
next.config.ts allowed wildcard { hostname: '**' }, allowing attackers to abuse Next.js image optimizer as an open proxy to probe internal/cloud services. 		Whitelisted Domains
Removed wildcard pattern. Pinned approved CDNs (dummyjson, pexels, unsplash, wikimedia, AWS S3). Arbitrary SSRF proxying is blocked.
HMAC Upload Signature Verification Timing Vulnerability
Direct string comparison sig !== expectedSig in /api/upload/local permitted byte-by-byte timing inference attacks. 		Constant-Time Defense
Enforced crypto.timingSafeEqual with exact buffer length verification, eliminating timing side-channel leaks.
Cron & Escrow Payout Authorization Timing Leak
Payout scheduler checked authHeader !== `Bearer ${CRON_SECRET}` via standard string equality. 		Constant-Time Verification
Secured with crypto.timingSafeEqual over equalized buffers, protecting sensitive automated vendor transfers.
Health Check Information Disclosure Verbose Error Leaks
/api/health returned raw e.message on DB errors, exposing PostgreSQL connection URIs, ports, and internal credentials. 		Sanitized Responses
Client receives generic status ("degraded", "unavailable"). Detailed traces and error objects are routed exclusively to internal Winston logs.

3. Data Layer, Injection Defense, Storage & DoS Mitigation
Security Vector Previous System (Yesterday) Current Hardened System (Today)
Structured Data JSON-LD (XSS) Stored XSS Risk
ProductJsonLd.tsx embedded raw strings in <script>. Malicious product titles with </script><script> could break out and execute code. 		Encoded Neutralization
Injected .replace(/</g, '\\u003c') to neutralize HTML script breakout tags into safe Unicode JSON literals.
Prisma ID Validation & Injection Defense Permissive / Loose Regex
Incomplete ID regex allowed ambiguous parameter inputs or failed on legitimate Prisma CUIDs, leading to inconsistent parsing. 		Strict Multi-Format Schema
Universal idSchema validating CUIDs, UUID v4, and MongoDB ObjectIds while rejecting SQL injection, traversal, and command payloads.
Ledger & Audit Trail (Soft Deletes) Hard Record Destruction
Products and reviews were hard-deleted (prisma.product.delete()), violating multi-tenant escrow audit trails. 		Preserved Soft-Deletes
Enforced deletedAt: new Date() soft-deletions across catalog and review operations, preserving historic transaction ledgers.
Rate Limiter Memory Bounds Memory Leak / DoS
In-memory token-bucket map grew unbounded without maximum capacity limits, exposing the server to out-of-memory crashes under IP floods. 		Bounded Capacity (10K)
Hardened with MAX_MEMORY_BUCKETS = 10000 and automated FIFO pruning of the oldest 20% of expired buckets.
High-Cost Endpoint Protection Uncapped Resource Drain
AI Copilot and coupon endpoints had no rate limits, allowing API balance exhaustion and coupon code dictionary brute forcing. 		Dedicated Rate Limits
AI API limited to 20 req/min with 2,000 char prompt limit and 20-message history cap. Coupon endpoint capped at 10 req/min.
File Upload Validation & Path Traversal Unbounded File Uploads
No explicit size cap before reading stream buffer; local storage allowed arbitrary file formats. 		Strict Allowlist & 5MB Limit
Enforced 5MB size limit, extension allowlist (jpg, png, webp, avif), and canonical path.relative traversal defense.
Content Security Policy (CSP) Unsafe-Eval in Production
CSP header permitted 'unsafe-eval' unconditionally across all production customer interactions. 		Production Hardened CSP
'unsafe-eval' is strictly disabled in production builds; image CDNs are explicitly allowlisted.
